# 视频场景切分工具

## 功能说明

自动识别视频画面中的 `conf` 值，当检测到 `conf=0` 时，切分视频片段（前10秒到后3秒）。

## 安装依赖

```bash
# 1. 安装 Python 依赖
pip install opencv-python pytesseract numpy

# 2. 安装 Tesseract OCR（必须）
# Windows: 下载安装包
# https://github.com/UB-Mannheim/tesseract/wiki
# 安装后添加到系统 PATH

# 或者使用 conda
conda install -c conda-forge tesseract
```

## 使用方法

### 基本用法

```bash
python video_scene_cutter.py "D:\桌面\历正\算法\数据集\huanyu\20260315燕郊比测"
```

### 完整参数

```bash
python video_scene_cutter.py "输入目录" -o "输出目录" --pre 10 --post 3
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `input_dir` | 输入视频目录 | 必填 |
| `-o, --output` | 输出目录 | 输入目录/cut_segments |
| `--pre` | conf=0 前多少秒 | 10 |
| `--post` | conf=0 后多少秒 | 3 |
| `--sample` | 采样间隔帧数 | 30 |

### 示例

```bash
# 处理燕郊比测视频
python video_scene_cutter.py "D:\桌面\历正\算法\数据集\huanyu\20260315燕郊比测"

# 指定输出目录
python video_scene_cutter.py "D:\桌面\历正\算法\数据集\huanyu\20260315燕郊比测" -o "D:\桌面\切分结果"

# 调整前后秒数
python video_scene_cutter.py "D:\桌面\历正\算法\数据集\huanyu\20260315燕郊比测" --pre 15 --post 5
```

## 输出格式

切分后的视频命名格式：
```
原视频名_scene01_conf0.mp4
原视频名_scene02_conf0.mp4
...
```

## 注意事项

1. **Tesseract 必须安装**，否则 OCR 无法工作
2. 确保视频画面中 `conf` 值清晰可见
3. 如果识别不准确，可以调整 `--sample` 参数（值越小检测越频繁但速度越慢）
4. 支持格式：`.mp4`, `.avi`, `.mov`, `.mkv`, `.flv`, `.wmv`

## 故障排查

**问题：提示找不到 tesseract**

解决：安装 Tesseract 后，在脚本开头添加路径：
```python
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'
```

**问题：识别不到 conf 值**

解决：
1. 检查视频画面 conf 值是否清晰
2. 尝试调整 OCR 参数（修改脚本中 `extract_conf_from_frame` 函数）
